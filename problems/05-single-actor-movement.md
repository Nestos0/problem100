# Problem 05 — 单个角色的移动提案

## 目标

将“角色想去哪里”与“角色这一小段时间内能移动到哪里”分开。

## 问题

定义立即行动意图：

```haskell
data Intent = MoveTo Position | Wait
```

角色具有速度。实现单角色移动提案：根据时间步长、当前位置、速度和意图，计算提议的新位置。本题只计算提案，不修改世界，也不处理其他角色。

## 约束

- 移动距离等于速度乘时间步长，但不得超过目标剩余距离。
- `Wait` 不改变位置。
- 负时间步长或负速度必须有明确行为；建议通过 `Either` 报告无效输入。
- 路径仍在连续空间中，不进行 tile 寻路。
- 本题不检查地形阻挡；后续题目会将提案与空间约束组合。

## 验收场景

- 速度为 `2`、步长为 `0.5` 时，未到目标的角色移动距离为 `1`。
- 角色剩余目标距离小于本步最大距离时，恰好停在目标。
- 等待意图不移动。
- 零速度不移动。
- 非法时间步长或速度不会产生无声的反向移动。

## 思考

为什么让这个函数返回“提案位置”而不是直接修改 `World`，能为后面的多角色冲突裁决留下空间？

## 可选拓展

改为“朝某个方向持续移动”的意图；处理方向向量长度不为 1 的情况，确保速度不意外随向量缩放。
