# Problem 02 — 由种子生成连续地形

## 目标

生成一个可重复的地形，并能在任意连续坐标查询地形。地形由区域描述，而不是由 tile 数组定义。

## 问题

定义一个有限的世界范围、地形区域和地形样本。每个区域至少包含圆心、半径和一种地表类型。地形本身包含默认地表及有顺序的区域列表。

实现以下概念性接口（具体字段可调整）：

```haskell
generateTerrain :: Seed -> Bounds -> Terrain
sampleTerrain   :: Terrain -> Position -> TerrainSample
```

使用给定种子确定性地产生若干地形区域。查询一个点时，如果它落在多个区域中，使用明确且稳定的优先规则；如果不在任何区域中，返回默认地表。

## 约束

- 同一个种子和相同参数必须生成相同地形。
- 采样接受任意 `Position`，不得先把坐标四舍五入成 tile。
- 区域列表是地形的领域表示；本题不做噪声算法或高精度地形侵蚀。
- 明确规定世界范围边界外的查询行为。

## 验收场景

- 相同种子调用两次，生成结果相等。
- 在区域圆心查询，得到该区域的地表类型。
- 在所有区域外查询，得到默认地表。
- 查询两个相邻但非整数坐标时，结果符合区域几何边界，而不是某个取整格子的结果。
- 重叠区域的查询结果符合你写明的优先规则。

## 思考

“地形由圆形区域保存”与“地形由格子保存”是领域表示的差异。未来若为加速查询建立网格索引，为什么它不应改变 `sampleTerrain` 的结果？

## 可选拓展

给地形增加连续高度采样；例如高度在区域中心高、边缘低，并在边界处连续变化。
