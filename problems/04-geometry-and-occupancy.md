# Problem 04 — 形状、地形区域与可占据性

## 目标

从“角色是一个坐标点”迈向“角色占据一片空间”，并判断角色能否进入某个位置。

## 问题

为角色增加圆形碰撞体；为地形增加圆形障碍区域。实现圆与圆的相交检测，以及：

```haskell
canOccupy :: Terrain -> Radius -> Position -> Bool
```

`canOccupy` 判断以指定位置为圆心、指定半径的角色能否完整放在地形中。不要只检查角色中心点是否落在障碍里。

## 约束

- 明确说明两个圆刚好相切时算可通过还是阻挡，并在所有函数中保持一致。
- 静态障碍区域不因查询而改变。
- 本题只处理圆形，不要求多边形、旋转碰撞体或角色间碰撞。

## 验收场景

- 明显远离障碍的角色位置可占据。
- 圆形角色完全落入障碍时不可占据。
- 角色中心在障碍外、但角色边缘侵入障碍时不可占据。
- 刚好相切的边界情况符合你写明的规则。
- 同一输入重复查询得到同一结果，查询顺序不影响地形。

## 思考

为什么 `sampleTerrain` 查询角色中心点，不能取代对角色整个形状的可占据性检查？

## 可选拓展

新增矩形障碍，同时让 `canOccupy` 的公开接口保持不变；把形状相交的细节留在几何模块中。
