# Problem 03 — 实体身份与世界状态

## 目标

让世界能够同时保存许多角色，并通过稳定身份找到、更新或移除指定角色。

## 问题

定义 `ActorId`、`Actor` 和 `World`。角色至少拥有身份、连续位置和移动半径。世界保存从身份到角色的映射。

实现添加、查找、更新位置和移除角色的操作。添加时若 ID 已存在，应返回明确错误，不能悄悄覆盖旧角色。

## 约束

- 不用角色在列表中的序号作为长期身份；列表顺序改变后，ID 仍指向同一角色。
- 世界中每个 ID 唯一。
- 世界映射的键必须与对应角色内部 ID 一致，或通过封装避免两份 ID 可不一致。
- 本题不需要 ECS，也不需要把所有角色字段放进一个无类型属性字典。

## 验收场景

- 插入角色后，按 ID 查询能得到它。
- 查询不存在的 ID 得到明确的“未找到”结果。
- 重复插入一个 ID 会失败，且原角色不被改写。
- 更新某个角色的位置不会改变其他角色。
- 移除一个角色后，其他角色仍可按原 ID 找到。

## 思考

哪些数据是“世界里这个角色当前的状态”，哪些操作应由 `World` 提供？如果每个模块都能任意改动映射，哪些不变量会变得难以维护？

## 可选拓展

把世界构造函数隐藏在模块内部，只暴露能够保持 ID 唯一性的操作。
