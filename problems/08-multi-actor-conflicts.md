# Problem 08 — 多角色同时移动与冲突裁决

## 目标

处理所有角色同时行动时发生的空间冲突，并让结果由明确规则决定，而不是由 ID 或容器遍历顺序偶然决定。

## 问题

角色都是具有半径的圆。每个角色从当前位置沿直线移动到 Problem 07 算出的提案位置。实现冲突检测和裁决：若任意两名角色在本 tick 的运动轨迹中发生身体重叠，则这两名角色本步停止。

停止某个角色会让它从“移动轨迹”变成“原地不动”。因此，解决一组冲突后要重新检查剩余角色是否与已停止角色发生冲突，并持续处理直到结果稳定。目标是得到保守但确定的规则，而不是模拟真实物理。

## 约束

- 开始时假设角色之间没有身体重叠。
- 检查整段 tick 中的轨迹；只检查最终位置会漏掉彼此穿越的角色。
- 所有相互冲突的角色都停止，不使用遍历先后挑一个赢家。
- 重复裁决必须在有限步内结束；每轮至少将一个新角色标记为停止。
- 边界相切是否算冲突沿用 Problem 04 的约定。

## 验收场景

- 两个角色各自移动到不相交的区域时，两者都移动。
- 两个角色争用相同终点时，两者都停止。
- 两个角色在一个 tick 中交换位置并穿过彼此时，两者都停止。
- A 与 B 冲突导致 B 停止后，若 C 的轨迹撞上停止后的 B，C 也停止。
- 反转角色输入顺序不会改变最终位置。
- 没有冲突的角色不会仅因另一个冲突组而停止。

## 思考

这条规则有意选择“冲突者全部停止”，而非推挤或选优先级。它实现简单且不偏袒某个 ID，但会不会过于保守？若改规则，哪些模块应改变，哪些模块应保持不变？

## 可选拓展

记录冲突事件（参与者、碰撞时间、接触位置），让后续伤害或声音系统读取事件，而不是直接插入碰撞算法内部。
