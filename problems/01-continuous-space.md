# Problem 01 — 连续空间：位置、向量与距离

## 目标

建立一个不依赖 tile 或数组格子的二维空间基础。通过类型表达“一个点”和“一个位移”是两种不同概念。

## 问题

实现二维位置和向量，以及基本运算。一个角色可以位于 `(2.5, -1.25)`；这个位置不需要取整，也不对应某个格子。

建议从下面的类型边界开始，字段表示可自行决定：

```haskell
data Position = Position Double Double
data Vector   = Vector Double Double
```

提供位置平移、两点间位移、距离和“朝目标移动最多给定距离”的函数。位置减位置应得到向量；位置加向量应得到位置。不要把位置直接相加定义成位置。

## 约束

- 空间使用连续二维坐标，不把坐标取整到 tile。
- 目标已经到达时，朝目标移动应保持原位，不产生除以零错误。
- 移动距离大于到目标距离时，应停在目标位置，不越过目标。
- 本题不处理浮点误差策略、旋转或碰撞。

## 验收场景

- `(0, 0)` 平移 `(2, -3)` 得到 `(2, -3)`。
- `(1, 2)` 到 `(4, 6)` 的距离为 `5`。
- 从 `(0, 0)` 朝 `(3, 4)` 移动最多 `2`，结果为 `(1.2, 1.6)`。
- 从 `(0, 0)` 朝自身移动任意非负距离，结果仍为 `(0, 0)`。
- 请求移动距离超过目标距离时，结果恰好为目标位置。

## 思考

为什么把 `Position` 和 `Vector` 设成不同类型，能让后续几何和碰撞规则更容易理解？

## 可选拓展

为非法负移动距离定义明确的错误返回类型，而不是默默接受它。
