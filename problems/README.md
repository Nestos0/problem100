# Continuous-World Simulation Problems

这组题目用 Haskell 逐步构建一个**没有 tile 作为领域概念**的全局模拟。角色、物体和地形都在连续坐标空间中；实现内部可以使用网格或索引做计算优化，但这些不能悄悄变成游戏规则。

按编号顺序完成。每题只增加一个主要能力：先让表示方式和规则变清楚，再把它们组合成全局模拟。不要急着预先实现后面所有系统。每题都应有自动化测试；当测试失败时，先构造最小场景解释失败原因。

## 建议的 Git 工作方式

这是一个逐题累积的项目：每完成一题，后题都建立在已完成能力之上。因此建议**一次只做一个短期题目分支**：从最新的 `main` 分支创建 `problem/01-continuous-space`，完成并测试后合并回 `main`，再从更新后的 `main` 开始下一题。不要让十个分支都从最初的空项目分叉，否则后题会缺少前题的代码。

一个题目内可以有多个小提交，例如“定义坐标类型”“实现运算”“补齐测试”；完成时合并题目分支。若分支切换给独立学习带来太多负担，直接在 `main` 上按题目提交也完全可行。分支是隔离实验的工具，不是学习目标。

当前工作目录尚未识别为 Git 仓库，所以这些分支名是建议的工作流，并非已创建的分支。请在真正的 Git 仓库根目录使用它们。
